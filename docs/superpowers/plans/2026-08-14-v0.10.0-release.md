# v0.10.0 Release — Live catalogs + MiniMax

**Date:** 2026-08-14  
**From:** develop after v0.9.0 (`5847d7e`)

## In this release

- Live catalogs from each user’s `/v1/models`, Ollama `/api/tags`, and `grok`/`agy` model lists
- Hourly TTL + startup refresh; successful fetch **replaces** (purge retired, add new)
- Empty/failed fetch keeps the last snapshot
- HTTP 404 force-refetches that provider and names current ids
- First-party MiniMax (`MINIMAX_API_KEY`, `api.minimax.io`)
- Codex via `codex exec`; Ollama from the local daemon
- Seed fallbacks updated from August 2026 live lists
- Playbooks: `docs/playbook-catalogs.md`, `docs/playbook-local-mcp.md`
